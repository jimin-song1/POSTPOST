# 사주빛 V5.6 V14: 실제 날짜 계산 명식 6개 교차검증 보고서

검증일: 2026년 11월 2일

## 무엇을 확인했나

V13의 기존 시험은 십성 정보를 인위적으로 재조합한 12개 사례였다. 이번에는 유효한 양력 출생일시 6개를 새로 정하고, POSTPOST `calculateSaju`로 원국, 십성, 명식별 후보를 계산했다. 시험일시는 가상 인물의 것으로, 실존 고객의 성격이나 개인정보를 다루지 않았다.

원래 프로젝트가 사용하는 `lunisolar-ephemeris` 패키지가 없어서, 절기 시각만 Python Swiss Ephemeris로 계산한 뒤 동일한 JS 패키지 인터페이스를 통해 제공했다. **JPL DE440 기반 운영용 절기 제공자와 완전히 동일한 환경이 아니다.** 절입 경계에 가까운 날짜는 시험에서 사용하지 않았다.

## 독립 역법 대조

KoreanLunarCalendar 라이브러리와 날짜별 **일주만 6개 모두 대조했고 일치**했다. 절기 기준 연주와 월주는 이 라이브러리의 음력 월력 표기와 판정 기준이 다를 수 있어 독립 검증 결과로 주장하지 않는다. 천문 절기 패키지를 달리 사용했기 때문에 운영용 공급자와의 경계시각 일치 검사는 남아 있다.

## 고객용 원고 시연과 AI 말투 검사

고객에게 실제 발송된 글이 아니라, 선택된 후보를 기준으로 수동 작성한 **3명식, 09번 강점과 10번 약점, 총 6개 소제목의 편집 시연 원고**를 별도 파일로 작성했다.

네가 정한 한국어 문체 검사 함수 `lintCustomerKoreanWriting`를 실행했다. 첫 검사에서 완곡한 어미 반복 1건을 발견해 수정했고, 최종 6개 시연 항목 모두 오류 없이 통과했다. 긴 줄표와 가운데점, 명백한 번역투와 자체 해석을 설명하는 표현도 포함하지 않았다.

이 검사는 문장부호와 주요 표현 패턴을 다룬다. 독자가 느끼는 개성과 실제 심리적 타당성을 증명하지는 않는다.

## 개발 수정 우선순위

1. **07번부터 다시 설계.** 서로 다른 다섯 명식에 같은 행동 설명이 선정되므로, 십성 두 개의 고정 대조에서 벗어나 궁위, 실제 합충, 계절, 격국 성립 상태를 활용할 조건을 검토해야 한다. 근거가 없으면 더 구체적인 행동을 만들어서는 안 된다.
2. **01번과 09번의 고정된 행동 설명 축소.** 같은 장면에 다른 명리 근거만 붙는 현상을 감사 경고로 표시하고, 소제목에 맞는 대체 후보가 없으면 고객용 자동 작성을 보류한다.
3. **기존 추상 후보 10개를 별도 품질 상태로 관리.** `READY_FOR_REVIEW`가 아니라 내용 보강 요청으로 남기는 것이 적절하다.
4. **AI 원고 전체 비교는 보류.** 실제 API 키와 의존성을 연결한 다음, 고객용 본문이 후보의 조건을 벗어나지 않고 소제목 사이의 의미도 반복하지 않는지 검증해야 한다.
