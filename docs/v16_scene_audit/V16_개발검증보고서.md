## 실제 변경
- `personality-behavior.v2.ts`: `specificExpressionScene`이 식신·상관과 계산된 보조 십성, 식상 위치를 근거로 설명 장면을 정함. 동일 십성 조합이라도 위치(연·월·일·시)의 해석 맥락이 다르면 표현이 달라질 수 있음. 위치별 표현은 검증된 심리 성향이 아닌 해석 가설임.
- `personality-behavior.v2.ts`: `specificStrengthScene`이 실제로 계산된 두 십성의 종류와 조합을 기록함. `scenarioRuleId`에 정확한 십성의 쌍을 연결함. 행동을 실증된 개인 특성으로 단정하지 않음.
- `personality-editorial.v1.ts`: 09번 강점 후보의 세부 규칙 ID가 실제 상징 계열과 사용된 두 십성에 부합하는지 검증하도록 확장함. 기존 가족 조합 ID도 허용.
- `verify-personality-scene-v16.cjs`: 60개 항목, 세부 장면 종류, 근거 ID, 금지 단정 표현 회귀 검사 추가.
