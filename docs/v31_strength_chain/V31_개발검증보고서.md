# 사주빛 V5.6 — V31 장점·부담 조건 구조화 검증

## 변경 내용
- `personality-editorial.v1.ts`에 `StrengthDevelopmentChain`과 `buildStrengthDevelopmentChain` 도입.
- 선택된 09번의 **원국 위치 / 증거 → 조건 → 판단 기준 → 관찰 가능한 행동 → 결과 언급 가능 범위**를 구조적으로 기록.
- 결과는 행동 원문에 결과·완성·마무리·수행·적용·확인 등 명시적으로 언급된 때에만 그 **행동 원문 자체**를 재사용함. 성취 여부를 새로 단정하지 않음.
- 10번 부담 조건은 `linkedStrengthCandidateId`가 실제 09번 후보와 일치할 때만 연결. 그렇지 않으면 임의 생성 금지.
- `createPersonalityWritingBrief`의 09번에 `strengthDevelopmentChain`을 선택적으로 포함. 기존 후보 선정과 작성 가능 상태 판정은 변경하지 않음.
