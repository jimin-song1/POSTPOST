# 사주빛 V18 — 09/10 연동 및 중복 판단 진단

## 범위
V17 로컬 ZIP 기반. 원국 계산기·명식별 서사 후보 생성 알고리즘은 그대로 둔다. 09와 타 항목의 문장/행동 수준 중복을 행동·판단근거·발휘상황으로 분리해서 기록한다. AI 생성 API 호출 없음. 운영/GitHub 미변경.

## 결과
- 12개 가상 출생정보 / 120항목. 이전 V17 표본을 다시 분석한 것으로 명식 선정 결과가 **119/120**인 상태는 해결되지 않았다.
- 09번과 다른 9개 항목의 108쌍 비교: 66쌍 구별 또는 미확정, 14쌍 단일 축 유사, 28쌍 비교 불가능. 두 축 이상 높은 유사성 감지는 0쌍. 이는 중복 부재나 성격 적중률을 증명하지 않는다.
- **RC11 P01-10이 비는 원인:** P01-09가 구조화 행동 가설 없이 추상(legacy) 후보로 선정됨. 10번은 근거 없는 역전 약점을 만들지 않도록 설계되어 차단됨. 고객용 자동생성을 해제하거나 근거 없는 문장을 대체 삽입하지 않음.
- 24개 항목에 `DO_NOT_GENERATE`/빈 후보 표시. 선정 개수와 실제 생성 승인 개수를 혼동해서는 안 된다.
- V18 코드 수정: 빈 항목과 특히 09번 근거 부족에 따른 10번 차단 이유를 감사 경고에 명시. 진단 스크립트 신설.

## 실행 확인 및 문제
- V18 3축 진단 스크립트: 실행 및 내부 단언 통과.
- 기존 오프라인 테스트 스크립트 10개 실행: 6개 종료코드 0, **4개 종료코드 비0** (V6, V8, V13, V15). 일부 버전 고정 숫자와 현재 소스가 불일치하는 것으로 보이나 모든 실패 원인을 확정하지 않았음. 따라서 V18은 **전체 회귀 통과 버전 아님**.
- 실제 AI API 문장 품질, 프로덕션 JPL 절기 계산, 타입체크 및 전체 빌드 미검증.
