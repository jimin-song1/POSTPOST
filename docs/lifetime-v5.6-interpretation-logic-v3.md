# 사주빛 V5.6 해석 로직 고도화안 — 계산과 글쓰기 사이의 '판단 엔진'

상태: **설계 문서 / 후보 규칙**. 배포 코드 변경 없음. 이 문서는 기존 V5.6 목차 및 \`lifetime-v5.6-evidence-map.md\`를 대체하지 않고 보강한다.

## 0. 비교 자료와 검증 범위

근거는 사용자가 제공한 '음양관 × 귀신사주 해석 방식 심층 분석' (음양관 221+233장, 귀신사주 141장, 총 595장 분량의 원본 캡처 중 대표 화면을 분석한 비교 보고서)이다. **이 단계에서 원본 595장을 새로 전수 검수한 것으로 간주하지 않는다.**

- 음양관의 강점: 원국·십성에서 직업, 계약, 재산, 시기까지 이어지는 *인생 전체의 연결성*; 단점: 비슷한 소재를 여러 장에서 반복.
- 귀신사주의 강점: 강한 개인화 헤드라인, 겉과 속의 차이, 구체적 생활 장면과 심리적 몰입; 단점: 신살 하나로 사건·전생·질병을 단정하는 과장.
- 사주빛은 **명리 계산의 재현성 / 독자에게 바로 이해되는 언어 / 경쟁하는 여러 해석 가설 중 타당한 것의 선별** 세 가지를 결합한다.
- '와, 이거 나 같다'는 **편집 만족도의 관찰값**이지 사주가 성격을 과학적으로 검증했다는 증거가 아니다.

## 1. 현 코드의 문제 (main 기준 실제 확인)

\`src/lib/saju/ai-interpretation/input-builder.ts\`:
- LIFETIME 입력은 원국·십성·지장간·합충·용신·오행의 원자료를 모으지만, **personality 섹션에는 십성·강약·격국만 전달하는 것과 마찬가지의 플랜 허용 evidenceIds를 부여**한다. 정작 일주 위치, 겉/속을 구분할 네 기둥, 합충, 용신 종합, 오행을 자유롭게 종합할 수 없다.
- \`talent-and-work\`, \`money-style\`, \`inner-roles\`에 같은 evidence prefix 그룹을 사용한다. 서로 다른 분야의 결론이 반복될 구조적 원인이다.
- 평생 대운만 전송하는 반면 연운·월운 및 CATEGORY 분야별 결과는 평생 총운용으로 충분히 전달되지 않는다.
- \`CONTEXT:CHILD_REALITY_UNKNOWN\`이 기혼 여부와 무관하게 실제 자녀 정보를 알 수 없는 상태로 남는다.
- \`WELLNESS:LIFETIME_CONTEXT\`는 높은 주의 기간 세 개만 추출해 청년·중년·노년 각 구간의 완결성을 보장하지 못한다.
\`src/lib/saju/ai-interpretation/grounding.ts\`:
- evidence ID가 존재하는지와 숫자·연도·간지·일부 확정 문구는 검증하지만, **'본문의 심리 주장 A가 인용한 근거에서 진짜 도출되는지', '이미 앞장에 쓴 장점을 반복하는지'를 판정하지 못한다**.
\`src/rules/lifetime-report.v2.ts\`:
- 현재 서비스는 18개 장의 구버전 목차. 확정 V5.6 소제목 단위와 불일치.

**따라서 단순 프롬프트 교체로는 근본 해결이 어렵다.**

## 2. 필수 아키텍처 — 6단계

\`\`\`text
POSTPOST 원국·오행·강약·격국·용신·운세(확정된 기계 계산)
    ↓
A. 증거 그래프 (계산 필드 ↔ 파생 관계; 같은 근거의 중복 집계 방지)
    ↓
B. 해석 후보 생성 (장점·부담·대비·특이성별로 여러 후보를 만들고 반대근거 검토)
    ↓
C. 후보 선정 (명리 근거의 타당성, 다른 사람과의 구별성, 소제목 적합성)
    ↓
D. V5.6 소제목 분배 (같은 서사/생활 예시 중복 금지; 장 전체의 균형)
    ↓
E. 고객 문체로 풀어쓰기 (생활 장면, 쉬운 한국어, 자신감과 근거의 비례)
    ↓
F. 명리·심리·문체·중복·일관성 검증 (실패시 후보 교체/재작성)
\`\`\`

### A. 증거 그래프

각 엔진 필드에는 \`evidence_id\`, \`original_source_ids\`, \`position\`, \`applied_rules\`, \`quality_status\`가 필요하다.
- **강약 48.57**은 독립적 심리 증거가 아니라 월령·천간·통근 등을 이미 계산해 만든 **종합 지표**다.
- '월지 유금 정관'과 '월령 관성 −18'은 같은 원자료를 공유한다. 이를 **두 개의 독립된 확인 증거**로 세지 않는다.
- '천간 을목 두 개'와 '천간 도움 +10'도 같은 원자료에서 파생됐으므로 중복 집계하면 안 된다.
- '종합 수 69.92'와 '수의 억부·격국·통관 우호'는 통합 점수와 그 계산 구성요소 관계다. 둘을 독립 실증으로 세지 않는다.
- 하나의 입력 요인만으로 날카로운 '숨은 성격'을 확정하지 않는다.

### B. 해석 후보

모든 소제목에서 **최소 3개 해석 후보를 생성한 뒤** 1~2개만 선정한다. *기계적 후보 갯수는 초기 개발 가이드이며 객관적 명리 법칙은 아니다.*

후보 타입:
- \`PRIMARY\` 가장 뚜렷한 기본 성향
- \`UPSIDE\` 잘 작동할 때의 장점
- \`DOWNSIDE\` 강점과 연결되는 비용/취약 조건
- \`CONTRAST\` 처음 보이는 모습 ↔ 익숙해진 뒤 / 조직 ↔ 개인 / 기회 ↔ 책임 등
- \`LESS_OBVIOUS\` 겉으로 드러나지 않을 수 있는 두 번째 성향 (반대 근거 포함)
- \`UNCERTAIN\` 전통 해석으로는 갈리는 후보; 강한 단정 금지/필요시 제외

**주의:** 장점/단점/의외의 면을 모든 소제목에서 억지로 세 개씩 나열하는 것이 아니라, PART 전체에서 균형을 이루도록 한다.

후보마다 반드시 다음을 구분:
\`\`\`json
{
  "hypothesis_id": "P01-CAND-03",
  "section_id": "P01-02",
  "topic": "첫인상과 가까워진 뒤",
  "claim": "대화의 친근함과 개인적 신뢰의 속도가 다를 수 있다",
  "evidence_ids": ["NATAL:PILLARS", "NATAL:TEN_GODS", "NATAL:HIDDEN_STEMS"],
  "relation_logic": "월주의 외부 역할과 일주의 개인적 반응을 비교",
  "counter_evidence_ids": [],
  "derivation_level": "TRADITIONAL_INFERENCE",
  "scope": ["낯선 모임", "개인적 관계"],
  "limits": ["내향/외향 확정 불가", "타인의 실제 평가 단정 불가"],
  "what_is_new": "낯가림과 신뢰 형성은 별개일 수 있음",

\`\`\`
필드 구조는 설계 예시다. 실제 토픽 ID는 V5.6 고유 식별자로 통일할 것.

### C. 해석 후보 평가 — 아직 검증되지 않은 '편집 점수'

**엔진의 강약점수/용신점수와 혼동하지 않는다.** 후보를 우선순위로 정하기 위한 내부 선별 척도일 뿐이다.

각 항목에 0/1/2(부적합/보통/높음)를 표시:
- **근거 적합성**: 그 명리 조합으로 해당 주장을 전통 해석 수준에서 뒷받침할 수 있는가?
- **구조적 대비**: 한 요소의 뻔한 키워드가 아니라 실제 상호작용·위치·제약을 설명하는가?
- **차별성**: 출생정보가 다른 고객에게 같은 문단이 그대로 들어가지 않을 가능성이 높은가?
- **생활성**: 하나의 현실적 장면을 *가정 예시*로 만들 수 있는가?
- **목차 적합성**: 같은 PART의 다른 소제목보다 해당 항목에서 다룰 타당성이 높은가?

패널티/보류:
- 같은 원자료 중복을 독립 근거로 센 후보 → 보류
- 원국에 없는 십성/신살, 불명확한 합화, 임의 용신 확정 → 탈락
- 건강·임신·재물·관계의 사건 단정 → 탈락
- 기존 문단과 핵심 주장/생활 예시가 사실상 중복 → 교체 또는 통합
- 전통 해석의 추론에 불과한데 실제 관찰 사실처럼 표현한 문장 → 표현 수위 하향
- 충분한 근거가 없는 '와!'를 위한 숨겨진 상처/배신/전생 만들기 → 탈락

검증 전 **합격점수·가중치·임계치 임의 설정 금지**. 실사용 블라인드 테스트로 보정할 것.

### D. PART/소제목별 '서사 소유권'

\`reportPlan\`에 \`narrative_slot\`과 \`previously_used_claim_ids\` 포함. PART별 대표 서사를 다르게 배치한다:
- PART01-01 기본 성격: 개인 기준 ↔ 사회적 기준의 **가장 큰 구조**
- PART01-02 첫인상: 낯선 관계 ↔ 깊은 신뢰가 형성된 관계의 **사회적 거리**
- PART01-03 혼자: 정보를 받아들이고 정리하는 **내적 행동**
- PART01-04 속마음: 생각과 표현의 **표면화 조건**
- PART01-05 선택: 정보, 위험, 책임, 기회 중 무엇이 **의사결정을 유발**하는가
- PART01-06 결정 이후: 판단 수정·지속의 **조건**
- PART01-07 양보: 권한·공로·경계의 **관계적 협상**
- PART01-08 난관: 예측 불일치·예상치 못한 압박에 대한 **대처**
- PART01-09 장점: 근거가 확인된 서로 다른 특성의 **상승효과**
- PART01-10 단점: 앞 장에서 나타난 특성이 특정 환경에서 **불리하게 뒤집히는 조건**
목차 이름/순서는 V5.6의 기존 원본과 일치시킨다. 위는 구조적 **권장 주제**이지, 반드시 모든 사람에게 같은 결론을 부여하는 템플릿이 아니다.

### E. 독자 문체

- 본문은 **'당신'에게 직접 설명하는 쉬운 존댓말**. 존댓말 혼용은 피한다. 기술 파트만 명리학 용어를 충분히 사용.
- 강한 첫 문장에는 **구체적으로 구분되는 주장**을 쓴다. "책임감이 강합니다" 같은 어디에나 들어갈 헤드라인을 피한다.
- 용신/강약/격국 수치는 해당 명리 부분이나 판단 이유를 전달할 때만 표시. 용신 결과를 성격 심리진단으로 바로 치환하지 않는다.
- “모르겠네요”, “일 수도 있겠습니다”, “가능성이 있습니다”로 문단을 반복해서 끝내지 않는다. 대신 **단정 대상의 범위**를 조절한다: "이 사주는 ...을 중요하게 읽어요" "이렇게 보게 되는 이유는 ..." "이때 살펴볼 점은 ...".
- 장면은 반드시 **예시/가정**으로 표현한다. 실제로 고객이 겪은 경험이나 타인의 평가라고 지어내면 안 된다.
- 모든 장이 장점→단점→조언의 똑같은 전개가 되지 않게 리듬을 달리한다.
- 반대되는 성질을 억지로 "고집 세지만 유연"이라는 모호한 문장으로 합치지 말고 **어떤 상황에서는 왜 A, 어떤 상황에서는 왜 B인지** 조건을 밝힌다.
- 문장을 세게 쓰는 것과 사실을 단정하는 것을 구분한다.

## 3. 실제 1995-09-30 테스트 원국 — 후보 선별 사례

**입력 원자료 (사용자가 POSTPOST로 실행한 값)**:
- 乙亥 / 乙酉 / 甲子 / 戊辰, −30분 보정 후 07:59
- 일간 갑목, 강약 48.57 **중화신약**
- 종합 수 69.92 / 화 65.48 / 목 65.00 / 토 52.95 / 금 52.22
- 수는 억부·격국·통관에서 도움 신호; **주용신 80점 미달 → 주용신 미확정**
- 조후는 정화 우선, 그다음 병화, 경금. 병약은 미적용.
- 금은 격국 유지의 장점과 억부 부담이 충돌함.

| 후보 | 명리 근거 | 주목할 조건 | 주의 |
|---|---|---|---|
| A. 규칙과 자율 | 월지 정관(酉) + 연월간 겁재(乙×2), 중화신약 | 규칙은 받아들이되 자기 판단권 침해는 다르게 느끼는 대비 | 원국에서 고객의 실제 직장 경험을 예언하지 않는다 |
| B. 경쟁의 다른 얼굴 | 겁재 2 + 정관의 평가축 + 일지 정인 | 이기고 지는 경쟁뿐 아니라 공정한 몫/기여의 인정·배움과의 관계 | "성과를 못 인정받았다"는 과거 사실로 쓰지 않는다 |
| C. 받아들이는 힘과 표현 | 일지 子 정인, 수 우호, 원국 화의 부재·조후 화 필요 | 배우고 이해하는 경향과 외부로 표현하는 과정의 차이를 **비교하는 가설** | 화 없음 → 말 못함/표현력 부족이라는 단정 금지 |
| D. 거래와 관계 | 시간 戊 편재 + 천간 乙 겁재×2 + 월지 정관 | 동업·정산·결정권·계약의 관계; PART04/05 소유 | 기본 성격 장에서 돈 얘기까지 과잉 확장하지 않는다 |
| E. 금의 양면성 | 정관이 격국 유지에 기여하지만 억부의 부담도 됨 | 조직의 규칙이 안정적 틀이면서 부담인 **조건부 양면성** | '중화신약=마음이 약함' 같은 심리적 오역 금지 |

A만 열 번 우려내지 말고, B/C는 성격 내 다른 섹션으로, D는 사업·재물로, E는 직장·심층풀이로 **서사 배분**.

**예시: PART01-07 양보하는 것과 끝까지 지키는 것(해설 스타일 샘플)**

> 서로 일할 때는 의견이 달라도 맞춰줄 수 있어요. 그렇다고 내가 한 일의 책임이나 공로까지 흐릿해지는 게 편한 건 아니에요. 가령 몇 사람이 함께 준비한 일이라면 모두의 몫을 존중하되, 누구에게 어떤 결정권이 있는지는 분명했으면 하는 쪽으로 읽혀요.
>
> 여기서 강점은 협업 자체를 피하지 않는다는 점이에요. 경쟁하는 마음과 규칙을 지키려는 마음이 함께 있어, 서로 납득할 기준이 마련되면 힘을 모으는 방향으로도 나타날 수 있거든요.
>
> 반대로 기준이 자꾸 바뀌는 환경에서는 일이 어렵다는 사실보다 '무엇을 기준으로 판단해야 하지?'라는 답답함이 커질 수 있어요. 이 사주는 경쟁을 무조건 피하거나 즐기는 사람이라는 말보다, 함께할 때의 기준과 몫에 민감한 방향으로 읽는 편이 더 구체적이에요.

이는 **전통 명리적 해석 후보를 보여주는 가상 장면**이지, 실제 이 사람의 행동을 관찰한 기록이 아니다.

## 4. 분야별 로직 재배치

| 분야 | 음양관에서 가져올 것 | 귀신사주에서 가져올 것 | 반드시 계산해야 할 차이 |
|---|---|---|---|
| 성격 | 원국·월령·십성의 인과 | 대비·의외의 면 | 사회/친밀/혼자/결정/갈등 등 위치별 조건 |
| 직업·직장 | 정관·인성의 조직 역할 | 평가·선택 순간의 현실 장면 | 업무 적성 vs 조직 만족 vs 승진 기회 |
| 사업·재물 | 편재·비겁·정관, 계약·분배 | 거래·동업에서 갈리는 판단 | 돈 버는 방식 vs 돈 관리 vs 동업 vs 확장 |
| 연애·결혼 | 일지·관성의 관계 조건 | 기대·서운함의 구체적인 생활 장면 | 기혼 문맥 우선; 실제 배우자 성격을 창작 금지 |
| 귀인·신살 | 실제 판정된 별, 해당 위치 | 읽고 싶은 제목·서사 | 신살 하나만으로 사건/상처 판단 금지 |
| 건강 | 조후/오행의 전통적 생활 균형 | 실제 루틴 장면 | 의료진단/임신확률/수명 연결 금지 |
| 대운·연운 | 원국+10년+1년+월+분야 합성 | 해마다 다른 제목·전환의 서사 | 도움(favorability) ≠ 변화(activation); 실제 시기 증거 |

## 5. 문장 검수 자동화와 평가

### 자동 하드 체크
- V5.6 소제목 ID와 가변 기간·제목 매칭.
- 입력에 없는 숫자·간지·용신 확정/합화·신살·기간을 서술하면 FAIL.
- 인용한 \`evidenceIds\`가 존재하는 것뿐 아니라 **각 \`claim_id\`의 근거 관계가 allowlisted rule인지** 검증.
- 심리 주장은 최소 하나의 전통 해석 규칙 ID와 조건 범위를 가져야 함; "근거 없음"은 FAIL.
- 의미가 사실상 같은 주장/예시를 동일 PART에서 중복 사용하면 FAIL/재분배.
- 반대 근거가 강할 때는 확정 어투 하향 또는 후보 교체.
- 현재 \`provider: mock\`를 진짜 모델 품질로 평가하지 않는다.
- 프로덕션에서 \`mock\`가 실제 고객 결과로 나가지 않도록 테스트.

### 인력 평가 (2종을 별도로 수집)
1. **독서 만족도**: 재미, 읽기 쉬움, 공감, 새로운 발견, 소제목 구분, 반복 부담.
2. **해석 내용 검증**: 맞다/틀리다/애매하다/확인 불가; 실제 근거를 안 보여주고 블라인드 판정.

모델이 이미 알고 있는 고객의 개인 정보(대화·메모리)를 절대 사용하지 않는 **엔진 단독 블라인드** 기준.

시험 명식은 다양하게 (천간·월지·격국·신강/신약·용신 관점 충돌·합충의 유무, 기혼/미혼·자녀 유무의 조합). 동일 명식으로 이름만 바꿨을 때 핵심 결론이 임의로 뒤집히면 FAIL. 명식을 바꿔도 내용이 거의 그대로면 FAIL.

### 교정 순서
1. **V5.6의 PART01 10개 항목**에 근거 후보 생성 기능 구현
2. 후보가 어떤 근거 조합에서 비롯됐는지 로깅/디버그 가능하게
3. 반대 후보 검토 및 섹션별 서사 배정
4. 10개 AI 문장 생성 (mock과 명확히 분리)
5. 심리 주장 근거, 표현·반복·문체 자동 검수
6. 최소 10명 이상의 서로 다른 명식과 비교, 점진적으로 확대
7. 검증 후 사업·재물·결혼·시기 등 다른 PART 확대

## 6. 금지해야 할 잘못된 추론

- "주용신 수 69.92" → **틀림**. 올바른 말: "종합 1위 수 69.92, 주용신 미확정".
- "중화신약 48.57" → 의지/성격이 약함 → **틀림**.
- "화(火)가 원국에 없다" → 말주변 없음/표현력 부족 → **틀림**.
- "금(金)이 조건부이고 관점 충돌" → 직장운 나쁨 → **틀림**.
- "귀인/삼재/귀문" → 특정 사건·병·상처가 있었다 → **틀림**.
- "한 가지 성향이 있다" → 모든 생활 장면에서 똑같이 행동 → **틀림**.
- "사용자가 예전에 말한 본인 성격과 일치" → 사주 계산이 이를 맞힘 → **틀림** (블라인드 분리 필수).
