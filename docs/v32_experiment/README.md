# 사주빛 V32 — RC11 후보 중복 판정 실험 / 기본 엔진 변경 보류

## 핵심 결과

- 기준 V31 엔진: 12개 가상 명식의 총 120항목 중 **119개 선정, 96개 구조화·원고 검토 가능**.
- V32 실험 분기: **120개 선정, 98개 구조화**. RC11의 09번과 10번이 구조화 후보로 선정됨.
- 그러나 실험에서 RC11 09번에 `SEMANTIC_OVERLAP`, `REUSED_SOURCE_PAIR` 경고가 함께 발생. 특히 01·08번과 `officer|resource` 의미 계열이 겹침.
- 따라서 120/120은 **선정 수 개선 실험 수치일 뿐, 해석 품질/실제 성격 적중률의 검증 결과가 아님**.

## 실험 변경

실험에서는 09번 후보에 한하여, 기존 모티프 겹침으로 중복 판단된 경우에도 서로 다른 출처 위치쌍·행동·발휘 상황·판단 기준을 갖추면 통과할 수 있는지 살폈다. 네 조건만으로 실제 행동 의미의 독립성이 입증되지는 않았다. V31 기존 중복 차단을 우회할 위험이 확인되어 **실험 변경은 선정 엔진에 반영하지 않았다**.

## 보관 자료

- `experimental_twelve_charts.json`: 실험 분기 12개 가상 명식의 결과. 프로덕션용 검증 자료 아님.
- `experimental_rc11_candidates.json`: RC11 후보 선정 판단의 실험 결과.
- `v32_validation.json`: V31 기준 결과와 실험 결과를 대조하는 독립 검사.

## 검증 범위와 제약

- 오프라인 Swiss 절기 fixture를 주입한 날짜 기반 명식 테스트로, 운영 환경의 원래 JPL 계산 경로와 동일하지 않다.
- 실제 AI API 고객용 원고, 성격 적중률, 심리학적 타당성을 입증하지 않는다.
- 기존 회귀 테스트 일부는 저장된 이전 결과 JSON만 확인하므로, 실행 성공만으로 현재 엔진 전체 재검증을 보장하지 않는다.
- RC11 중복을 해결하려면 표면 문구/트리거 차이 외에 *행동의 목표·산출물·선택 후 결과* 등 서로 다른 사건임을 입증할 명식 기반 편집 근거가 추가되어야 한다.
- GitHub나 운영 배포를 변경하지 않음. 배포 차단 유지.
