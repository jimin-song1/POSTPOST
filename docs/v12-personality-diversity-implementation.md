# 사주빛 V5.6 성격 해석 V12 개발 및 검증 보고서

작성일: 2026년 11월 2일

## 개발 목표

V11의 교차 명식 검사에서 확인한 문제를 개선했다. 09번 강점이 앞선 소제목과 같은 십성 이름을 사용했다는 이유만으로 제외되는 규칙을 고쳤다. 10번 약점은 09번에 실제로 선정된 구조화된 강점 후보를 참조한 경우에만 생성한다. 02번, 03번, 05번, 08번의 상황 문구도 원국의 십성 계열에 따라 선택하도록 바꿨다.

### 수정한 코드

- `src/lib/saju/ai-interpretation/personality-behavior.v2.ts`: 공적, 사적 장면과 혼자 있는 시간, 선택, 문제 대응을 십성 계열에 맞게 달리 구성한다.
- `src/lib/saju/ai-interpretation/personality-editorial.v1.ts`: 09번에서는 같은 십성 이름이더라도 원국 위치와 행동 장면이 다르면 후보를 검토한다. 05번과 내용이 실제로 겹치면 여전히 제외한다. 10번은 검증된 09번과 원국 위치 한 곳을 공유하고 새로운 위치 하나를 추가한 경우에만 선정한다. 다른 소제목에서 사용한 위치쌍과 완전히 같다면 우선순위를 낮춘다.
- `scripts/check-cross-chart-v11.cjs`: 지난 실험의 12개 재조합 사례를 이번 결과에도 그대로 사용한다.
- `scripts/verify-personality-diversity-v12.cjs`: 새 조건과 오류 검출을 재실행할 수 있는 13개 검사.
- V6, V7, V9 오프라인 검사의 이전 가정을 변경했다. 과거에는 같은 십성 쌍을 다시 쓰거나 중복 검토 경고가 남으면 무조건 실패했다. 이제 09번과 10번의 별도 역할 및 10번의 근거 연결을 확인하고, 실제 중복 경고는 편집 검토 대상으로 기록한다. **따라서 이번 67개 통과를 과거의 67개 검사와 조건까지 완전히 동일한 결과로 볼 수 없다.**

## 동일 12개 모의 명식 비교

| 검사 지표 | V11 | V12 |
|---|---:|---:|
| 전체 후보 선정 | 109/120 | 117/120 |
| 조건부 행동 후보 선정 | 51/120 | 67/120 |
| 09번의 구조화된 장점 후보 | 1/12 | 9/12 |
| 10번의 장점 연결 약점 후보 | 1/12 | 9/12 |
| 02번 상황 문구 종류 | 1 | 5 |
| 03번 상황 문구 종류 | 1 | 2 |
| 05번 상황 문구 종류 | 1 | 4 |
| 08번 상황 문구 종류 | 1 | 5 |
| 검수용 원국 위치 불일치 | 없음 | 없음 |

전체 사례에서 시주, 월주, 연주, 일주 정보를 재조합해 십성 신호를 다시 계산했다. **실제 출생일시를 기반으로 만세력을 모두 재계산한 명식이 아니다.** 격국, 용신, 강약, 대운, 합충 등 다른 파생 조건은 시험에서 비활성화했다. 따라서 위 수치는 특정 소프트웨어 규칙의 동작 범위만 보여준다. 실제 고객의 성격 적중률이나 다양한 명식의 실제 분포를 나타내지 않는다.

## 현재 남은 문제

1. 09번과 10번이 모두 구조화된 장면으로 연결되지 않는 사례 3개는 일반적인 설명형 후보 또는 미선정 상태다. 이 상태를 자동 합격 처리하면 안 된다.
2. 10번의 상황 도입 문구는 아직 9개 선정 사례에서 같게 나타난다. 실제 강점의 구체적인 부담 조건은 고객용 원고에서 다시 평가해야 한다.
3. 기준 가상 명식에서 07번과 10번이 `role-boundary`, `opportunity-choice`를 함께 사용한다는 의미 중복 경고 1건이 남아 있다. 이 경고는 제거하지 않았다.
4. 상징에서 행동을 도출하는 추론은 검증된 심리 측정이 아니다. 연결 근거가 있다고 실제 습관이나 내적 동기를 확인한 것으로 쓰면 안 된다.
5. 이번에는 실제 OpenAI API를 호출하지 않았다. 최종 고객용 문장은 별도 생성과 독자 평가가 필요하다.

## 검사 결과 및 한계

- V6부터 V10까지의 오프라인 회귀 검사: 10 + 14 + 16 + 12 + 15 = **67개 통과**. 앞서 설명한 일부 검사 기준 변경을 반영했다.
- V12 신규 오프라인 검사: **13개 통과**.
- 교차 명식 검사: 별도 내부 검증 5항목 통과. 실행 오류와 검증되지 않은 원국 위치 참조는 발견되지 않았다.
- 수정 TypeScript 문법: 별도 전사 검사 통과.
- 전체 `tsc --noEmit`은 실패했다. 환경에 Next.js, React, Zod, Node 타입 선언 등 프로젝트 의존성이 없어 모듈을 찾지 못했다. 따라서 전체 타입 검사와 서비스 빌드를 통과했다고 말할 수 없다.
- 정식 Vitest 및 서비스 AI API 실행은 수행하지 않았다. GitHub와 운영 서비스는 변경하지 않았다.

## 재실행

```bash
cd POSTPOST
npm run test:personality-diversity-v12
```

오프라인 검사에는 Node.js 22와 TypeScript 실행 환경이 필요하다. `typescript` 모듈을 일반적으로 찾지 못하면 시스템 전역 설치 경로를 사용한다. 일반 환경에서는 `npm install` 이후 실행할 것을 권장한다.

비교 데이터는 `docs/v11_cross_chart/results.json`, `cases.csv`, `per_section.csv`, `selected_claims.csv`에 있다. V12 자체 검사 결과는 `docs/v12_diversity_results.json`을 참조한다.
