# 사주빛 V30 — 장점 장면 실험 및 회귀 방어

## 결론
V29 기반 장점 장면의 실제 행동/결과물 차별화를 실험하였지만, 새 문구를 엔진에 반영하면 과거 V9의 출력 근거를 갖춘 강점 선정 검사 12개 중 1개가 실패하거나 V15의 6명식 구조화 후보가 50개에서 48개로 감소하는 회귀가 관찰되었다. 근거 없는 성취 능력이나 출력 신호를 만들 수 없으므로 해당 실험은 **폐기**했다. 최종 V30 소스의 `personality-behavior.v2.ts`는 V29와 동일하다.

## 완료한 작업
- RC11 09번 후보의 행동·근거 연결과 10번 차단 원인을 재확인했다.
- 편재·상관 등 출력 신호가 있는 후보에서 결과물 중심 장면을 작성하는 실험을 진행했다.
- 실제 선정 로직 회귀가 발생하여 소스 변경을 되돌렸다.
- `scripts/verify-personality-v30-quality-gate.cjs` 신규 추가: 6명식, 12명식 선정·구조화/검토 가능 수, RC11 미선정 여부를 누락 없이 점검.

## 최종 V30 기준 재검증
- 6명식: 60/60 선정, 구조화 50개.
- 12명식: 119/120 선정, 구조화 96개, 검토 가능 96개, 비구조화 23개, 공란 1개.
- RC11 09번은 비구조화 후보가 선정됨. 10번은 미선정.
- 새 V30 품질 게이트: 4/4 통과.
- Node 오프라인 회귀: V6, V7, V8, V9, V10, V12, V13, V14 realcharts, V14 copy, V15, V29 총 11개 스크립트의 엔진 원복 전후 결과 중 **최종 상태는 기준 소스로 원복하여 V9/V15 재검사 통과를 확인**함. 완전한 타입 검사, Vitest, 고객용 AI API는 실행하지 않음.

## 다음 수정 제안
- 09번에서 출력 십성 유무뿐 아니라 후보 행동이 실제 결과물/실행인지 검증하는 독립적인 장면 계약을 도입.
- 새 장면을 먼저 shadow 후보로 평가하고 V9의 출력 구조와 V15의 구조화 수를 유지하는 경우에만 선택 엔진에 병합.
- 기존 RC11 09/10 공란을 임의 문구로 채우지 않고 명식 근거가 허용하는 후보를 찾는 방식 유지.

이번 결과는 오프라인 명식·문구 검증이며 성격 적중률이나 서비스 배포 승인을 뜻하지 않는다. GitHub 및 운영 서비스 변경 없음.
