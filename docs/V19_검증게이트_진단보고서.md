# 사주빛 V19 — RC11 원인 분석 및 배포 차단 게이트

기준: V18 전체 소스. 이번 버전은 **실패 원인의 재현과 배포 승인 오판 방지**에 집중한 진단판이며, 후보 생성 알고리즘을 개선 완료했다고 주장하지 않는다.

## 재현 결과
- 가상 출생일시 12개, 120개 항목 중 **119개 선정**. **실제 구조화된 행동 가설 및 원고 검토 가능 상태는 96/120**이며 나머지 24개는 `DO_NOT_GENERATE` 또는 미선정.
- RC11의 09는 레거시 후보 `V56-X-P01-09-2`가 선정되었지만 `DO_NOT_GENERATE`로 표시된다.
- RC11의 09에 대한 구조화 후보 7개가 앞 항목과의 행동 의미 중복 판정으로 탈락. 10번은 검증 가능한 09의 행동 가설이 없기 때문에 미선정되는 안전 차단이 유지됨.
- 단순히 09의 중복 판정을 완화하거나 10번에 일반적인 약점을 강제로 넣으면 근거 없는 개인화 문장이 될 수 있으므로 이번 버전에서 금지.

## 회귀 검사 재실행
13개 진단/검사 중 V6, V8, V13, V15 스크립트가 비정상 종료. V7, V9, V10, V12, V14(real/copy), V16, V17, V18은 정상 종료. 성공 종료가 반드시 전체 정확성을 의미하지 않음.
- V6: 10개 중 9개 성공.
- V8: 16개 중 15개 성공.
- V13: 15개 중 10개 성공; 기대 선정 118/구조화 69와 현재 선정 115/구조화 63이 불일치하고 09/10 관련 가정도 어긋남.
- V15: 7개 중 6개 성공; 현재 행동 종류 45종 대 고정 기대값 차이 포함.

각 스크립트의 전체 로그는 `docs/v19_diagnostics/*.log`에 기록. 고정된 구버전 수치를 무조건 완화하여 회귀 통과라고 선언하지 않음.

## 신규 도구
`scripts/verify-personality-release-gate-v19.cjs`는 12명식 결과와 회귀 로그를 읽어 `docs/v19_diagnostics/release_gate.json`을 생성한다. `releaseReady`가 `false`이면 **배포 불가**. 이 스크립트 자체의 종료 코드 0은 진단이 정상 실행됐다는 의미일 뿐, 배포 승인 아님.

## V20 우선순위
1. RC11 09 후보 7개가 왜 의미상 겹치는지 상위 항목별 행동/판단/상황 비교 후, 중복 없는 새 장면만 근거에 맞춰 생성.
2. 연결된 10번은 09의 실제 근거 중 하나를 이어받되 새 위치와 부담 조건을 명확히 구분.
3. 24개의 비승인 항목을 후보 부족, 구조화 누락, 근거 부족으로 분류해 개선. `120/120 선정`과 `120/120 고객 원고 승인`은 별개의 목표.
