# 사주빛 V23 중복 판정 위험 진단

- 원본 V22 편집기 판단을 유지한 읽기 전용 감사. 12개 명식의 저장 결과 사용.
- RC11 09번 후보 **9개 모두 SEMANTIC_OVERLAP으로 탈락**, 10번 미선정 유지.
- 기존 에디터가 보고한 충돌 대상과 원국 출처 공유 여부를 비교함.
- 실제 guard를 모의 입력으로 테스트: **같은 모티프·다른 행동**도 중복 처리 가능, **다른 모티프·같은 행동**도 미검출 가능.
- 따라서 단순 모티프 경계 완화는 안전하지 않음. 다음 버전은 행동/판단기준/트리거 별 검증된 구조화 특징이 필요.
- 문장 3-gram은 보조 진단일 뿐 실제 의미 판정이 아님.
- 현재 선정 119/120, READY_FOR_REVIEW 96/120. 실제 고객용 AI API 원고 검증 안 함.
