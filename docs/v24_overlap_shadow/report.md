# V24 중복 판정 개선 예비 실험

- 행동·판단기준·상황 세 축의 텍스트 유사도 진단을 별도 구현함.
- 같은 행동 문구는 모티프가 달라도 차단하는 규칙을 테스트함.
- 모티프는 같지만 행동이 다른 경우 자동 허용하지 않고 수작업 검토 대상으로 분류함.
- 실제 선정 엔진은 변경하지 않았으므로 120/120 복구로 보고하지 않음.
- RC11 후보 9개는 V21 데이터에서 전부 중복 판정으로 탈락한 상태.
- 패턴 검사 통과는 고객 성격 적중률이나 실제 의미적 구별의 검증이 아님.
- 원고 검토 가능 수 96/120, 기존 회귀 실패 4건은 별도 해결 필요. 배포 금지.
