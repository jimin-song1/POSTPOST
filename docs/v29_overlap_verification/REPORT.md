# 사주빛 V29 — 보수적 행동 중복 판정 보강

기준: V28 로컬 소스. GitHub 및 운영 서비스 미변경.

## 실제 코드 변경
`personality-claim-guard.v1.ts`의 `behavioralOverlap`에 observableBehavior의 정규화 후 완전 동일 여부를 중복 판정에 추가했다. 기존 모티프 기반 중복 차단 규칙은 유지한다. 서로 다른 문장이라는 이유로 의미상 중복을 자동 해제하지 않는다. 기존 행동 가설을 수정하거나 새로 생성하지 않았다.

## 재검증
- 독립 판정 테스트 4/4 통과 (동일 행동·모티프 다름, 문장부호 차이, 동일 모티프·행동 다름, 둘 다 다름)
- 오프라인 Swiss 절기 어댑터 기반 12개 가상 명식 재계산 완료: 120항목, 119개 선정, 96개 구조화·원고 검토 가능, 미선정 1개
- 기존 V6/V7/V8/V9/V10/V12/V13/V14/V15 스크립트 9/9 실행 및 통과. `logs/` 기록.
- V19 배포 게이트는 정상 실행했으나 저장된 오래된 실패 기록을 읽으므로 `releaseReady:false`, `failedRegressions: [V6,V8,V13,V15]` 반환. 이는 **이번 회귀 검사를 다시 실패했다는 의미가 아니다**. 저장된 게이트 입력 갱신 및 독립 배포 평가가 별도 필요하다.

## 미해결
- RC11 09번은 구조화 후보 전부 모티프 중복으로 탈락하며 추상 후보가 선정되고 10번은 미선정. 이번 변경으로 복구되지 않음.
- 의미 유사성의 정확도/재현율, 실제 AI API 원고, 실제 성격 적중률은 검증하지 않음.
- **배포 불가**. 다음 버전에서 강점 장면의 독립 행동·발휘 상황 근거를 추가하되 원국 증거 계약을 지켜야 함.
