# POSTPOST 사주빛 V5.6 — 성격 우선순위 로직 고도화 보고서

기준 소스: `사주빛_V56_성격다양성개선_전체소스.zip` (이전 로컬 V5.6 개발본). GitHub `main`·운영 배포·기존 명리 계산 엔진 변경 없음.

## 이번 개선의 핵심

이전에는 후보 생성 자체를 다양하게 만들었지만, 대부분 `서로 다른 원국 위치 수 + CONTRAST 여부 + 임의 편집 우선도`로 첫 문장을 선택했다. 이제 `personality-priority.v1.ts`에서 실제 계산된 월지·월간·일지와 격국 성립/손상, 직접 합충 관계의 **해석 맥락**을 확인하고, 후보 순위의 이유/주의를 함께 기록한다.

- 월지 본기를 후보가 실제 인용했을 때에만 편집 우선순위에 반영.
- 격국은 `source.tenGod`, `source.branch`, `status`, `confidence` 확인 후 반영. 미성립·혼재/손상은 주의 신호로 남김.
- 합충형파해는 원국의 두 문자·기둥·종류가 엔진 관계 증거와 일치해야만 반영. 합과 합화 성립은 구별.
- 조정 강약과 용신 synthesis의 선호/충돌은 **심리 능력·성격 강약의 점수로 환산하지 않음**. 근거의 맥락을 설명하는 참고 신호로만 기록.
- AI 브리프에도 실제 확인된 `NATAL:RELATIONS`, `NATAL:STRUCTURE:QUALITY` 근거를 전달하고, 존재하지 않는 격국 근거를 인용하지 않도록 처리.
- 후보마다 `prioritySignals`·`counterConsiderations`·내부 편집 순위를 남김. 순위는 심리 검증 점수가 아닌 제작용 **휴리스틱**이며 고객에게 수치로 노출하지 않음.

## 수정 전후 6명식 비교

첫 번째는 기준 비교 명식이고, 나머지 다섯 개는 가상 출생정보에 대한 테스트다. 이전 로컬 결과와 같은 출생정보로 새 결과를 재계산함.

| 사례 | 이전 성격 10항목 완성 | 새 성격 10항목 완성 | 첫 해석 후보가 바뀐 항목 |
|---|---:|---:|---:|
| A | 10/10 | 10/10 | 6/10 |
| B | 10/10 | 10/10 | 7/10 |
| C | 10/10 | 10/10 | 7/10 |
| D | 10/10 | 10/10 | 6/10 |
| E | 10/10 | 10/10 | 8/10 |
| F | 10/10 | 10/10 | 8/10 |

**총 60개 항목 중 42개에서 대표 후보가 달라짐.** 이는 월령·자리에 대한 후보 우선순위가 변화했다는 뜻이지, 실제 인물의 성격을 더 정확히 맞혔다는 뜻이 아님.

선정 사례 (기준 명식 A의 성격 첫 항목):
- 이전: `V56-P01-A`
- 수정: `V56-X-P01-01-3`
- 선택한 근거 신호: `MONTH_COMMAND:2, DAY_BRANCH_CONTEXT:1, SECTION_POSITION_FIT:1, STRUCTURE_UNCERTAIN:-1, DIRECT_RELATION:1`
- 새 핵심 가설: 일지 정인의 '익숙한 근거와 체계적 학습'와 월지 정관의 '분명한 절차와 공식적인 책임'를 비교하며 평소 어떤 기준을 자신의 중심으로 삼는지 살펴본다. 핵심은 서로 다른 두 십성 계열이 연결되는 점이다.

## 해석 주의/남은 과제

1. 현 순위 조정값은 전통적 설명의 근거를 풍부하게 만드는 **편집 휴리스틱**. 더 높은 숫자가 그 사람 성격의 확실함을 뜻하지 않음.
2. 격국·월령·합충의 해석 적용을 엄밀하게 설명할 수는 있어도 심리 특성의 실제 관찰로 확정할 수 없음.
3. 용신의 억부/조후/통관/병약/격국 통합 결과를 성격의 성능 점수로 직접 사용하지 않는 안전한 설계. 용신을 진로·시기·상징으로 사용하는 후속 범위는 별도 설계 필요.
4. 문장들의 **의미상 중복** 검출은 아직 제한적. 실제 고객 읽기 평가와 명식 블라인드 테스트 필요.
5. 기존 V2 보고서 런타임 미연결. V5.6 별도 초안 생성기는 여전히 `draft_needs_review`로만 제공.
6. GitHub 원격 PR/머지/운영 배포는 이번 작업에서 하지 않음.
