# 사주빛 V5.6 V1·V2 후보 블라인드 비교 및 선택 로직 보완 검증

> 2026-10-27 / 기준: 사용자가 전달받은 V2 전체소스 ZIP vs 직전 우선순위 전체소스 ZIP. 이 보고서는 **명리 계산 결과에서 선택된 후보**를 비교한 것이다. 실제 OpenAI API가 작성한 유료 고객 문장의 블라인드 비교는 **아니다**.

## 대상 및 공정성

- 동일 입력: 프로젝트에 포함된 **가상 명식** `SYNTHETIC_CORE_001` (`甲辰 / 丁卯 / 乙未 / 壬午`); `samples/SYNTHETIC_CORE_001.json`의 저장된 분석 결과를 그대로 사용했다. 실제 사용자 개인정보나 과거 평가를 주입하지 않았다.
- V1·V2 모두 각 버전의 `selectPersonalityInterpretations`와 동일한 저장 분석 결과를 사용했다.
- 종전 V1과 첫 V2를 보존한 채, V2의 **해석 적합도·대비 중복·한국어 조사 문제**를 수정하고 다시 실행했다.

## 대표 해석의 실제 차이: 05번 선택 기준

**V1의 내부 주장:** 일지 편재의 '다양한 기회와 자원 배치'와 시간 정인의 '익숙한 근거와 체계적 학습'를 비교하며 중요한 선택 앞에서 무엇을 먼저 따져보는지 살펴본다. 핵심은 서로 다른 두 십성 계열이 연결되는 점이다.

**수정 V2의 내부 주장:** 새로운 제안에 비용·책임·기회가 동시에 붙어 있을 때의 조건부 해석. 우선 확인할 기준: 열려 있는 선택지와 기회비용. 함께 검토할 기준: 이미 알고 있는 정보와 이해의 근거.

**수정 V2가 AI에게 전달하는 행동:** 눈에 띄는 장점보다 우선 확인할 조건을 선택하는 모습. 이때 "열려 있는 선택지와 기회비용"에 먼저 무게를 두고 "이미 알고 있는 정보와 이해의 근거"도 살펴보는 모습

**수정 V2의 반대 조건:** 손실이 작고 되돌릴 수 있는 선택이라면 간단히 결정할 수도 있음. 특히 설명을 검토할 시간이 주어질 때에는 후자의 기준이 앞설 가능성도 함께 검토

V2는 상황과 반대 조건을 **분리해 전달한다는 점**에서 V1보다 정보 구조가 상세하다. 하지만 실제 행동을 관찰한 것이 아니므로 `정확하다`, `놀랍게 잘 맞는다`라는 평가는 할 수 없다.

## 이번 소스에서 적용한 수정

1. 소제목의 십성 계열과 관련 없는 후보는 V2로 강제 선택하지 않음. 양쪽 신호가 모두 영역의 핵심 비교군에 속해야 한다.
2. 두 신호의 십성 계열이 같다면 행동의 대조라고 과장하지 않음.
3. V2 대표로 선정된 다른 소제목과 **완전히 같은 두 십성**의 대비를 다시 사용하지 않음.
4. `과(와)`, `을(를)` 같은 선택 조사 토큰을 삭제하고 자연스러운 중립 구문으로 변경.
5. V2 후보가 선정되지 않아 기존 추상 후보로 넘어간 02·08·10번은 감사대장과 Writing Brief에 **구체성 심사 필요** 경고를 남김.
6. 관련 Vitest에 섹션 관련성·대표 대비 중복·비문법적 조사 방지 검사를 추가.

## 남아 있는 문제 — 출시 판정

- **서술의 새로움과 심리적 정확도 미검증.** 템플릿 장면이 아직 고정돼 있어 행동 후보를 더 구체화해야 한다.
- 귀신사주에서의 `행동 뒤의 예상 밖 동기` 같은 강한 묘사를, 현재 데이터만으로 사실처럼 생성할 수 없다. 실제 검증 없는 심리 단정은 넣지 않는 게 맞다.
- **전체 타입 검사/Vitest/Next.js 빌드 미완료.** 현재 작업 컨테이너의 npm 종속성 다운로드가 실패했다. 전용 타입스크립트 전사(구문 검사)와 저장 샘플의 오프라인 실행 검사만 수행.
- **실제 OpenAI API 호출 미수행.** 동일 명식 V1·V2 실작성문 비교는 API 실행이 가능한 환경에서 진행해야 한다.
- 원본 명리 해석의 실제 정확도는 계산 정확도와 별개로 검증되지 않았다.
