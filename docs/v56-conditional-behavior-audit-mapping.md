# 사주빛 V5.6 조건부 행동 해석 V2 — 경쟁사 문장 검수 결과 반영표

## 적용 범위

2026-10-27 받은 경쟁사 검수 결과에는 귀신사주 141장과 음양관 1편 221장, 2편 233장의 전사본 및 문장별 분석표가 포함돼 있다. 세 작업의 전사·태깅 검증 수준이 같지 않다. 원문 전사의 일부 판독불가·미캡처 구간, 문장별 자동 분류 및 수작업 표본 검수의 한계를 그대로 따른다. 경쟁사의 실제 비공개 코드/모델 프롬프트는 알 수 없으며, 본 구현은 **문장 패턴 관찰에서 도출한 자체 설계**다.

## 구현 경계·남은 일

1. 이번 변경은 행동 후보 **표현을 구조화**한 것으로, 해당 행동이 실제로 맞는지 검증하지 않는다.
2. 격국/지장간은 검증된 명리 사실과 우선순위의 맥락으로만 쓰인다. 이들만으로 감춰진 트라우마·공포 등의 인격 사실을 만들어내지 않는다.
3. 각 소제목에 정해진 질문과 기본 장면이 여전히 남아 있어서, 사람마다 진짜로 새로운 특징을 찾아낸 수준의 판단은 아직 아니다. 독립 피험자의 블라인드 평가가 필요하다.
4. 기존 파트 01 외 직업·사업·재물·관계·연운 전체 공통 Fact Sheet/claim ledger는 구현하지 않았다.
5. 실제 유료 OpenAI 생성 결과는 이 작업에서 검증하지 않았다. 출력 금지 패턴은 예시 기반으로, 자유 서술 전부를 완전 차단하지 못한다.

## 재현

`npm ci` 후:

```bash
npm run typecheck
npm test -- tests/personality-behavior.v2.spec.ts tests/personality-coverage.spec.ts tests/personality-editorial.spec.ts tests/personality-generation.spec.ts
npm run build
```

구현과 별도로 고객용 해석이 이질적인 명식 6~36개에서 충분히 구별되는지, 각 문장에 원국 근거가 있는지, 평범한 성격 명제가 반복되는지 직접 읽고 평가해야 한다.
