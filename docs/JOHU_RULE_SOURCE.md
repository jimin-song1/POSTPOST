# JOHU rule source and curation

## Provenance

`johu-qiongtong-v1`은 위키문헌의 [《窮通寶鑑》/《欄江網》 계열 전문](https://zh.wikisource.org/zh-hant/%E7%A9%B7%E9%80%9A%E5%AE%9D%E9%89%B4)을 2026-09-24에 대조하여 편집했다. 원문의 `論甲木`부터 `論癸水`까지 각 일간의 正月~十二月 절을 source section으로 삼았다. 웹의 단일 요약표를 120칸으로 복제하지 않았다.

원문의 `先用`, `次用`, `專用`, `為尊`, `為佐`, `參酌`, `不可少`를 순서·역할로 보수적으로 정규화했다. 명확한 선후는 PRIMARY/SECONDARY, 함께 쓰되 뒤따르는 것은 SUPPORTING, 참작·보조는 OPTIONAL로 두었다. 원문의 부귀·빈천·질병·수명·장애·시험·신분·성별 평가는 데이터와 상품 출력에서 제외했다.

월은 절기 계산으로 얻은 지지 寅~丑이며 양력 월 번호나 음력 월 번호를 조회 키로 사용하지 않는다. 정월~십이월은 각각 寅·卯·辰·巳·午·未·申·酉·戌·亥·子·丑에 대응한다.

## Conditions, blockers, and ambiguity

기본표와 조건을 분리한다. v1의 명시적 priority override는 `甲+酉` 한 건이다. 八月甲木 절의 `支成木局, 干透比劫, 反取庚金為先, 次用丁火` 문맥을 `WOOD_GROUP + visibleCompanion` 조건으로 구조화하며 기본 `丁→丙→庚`을 `庚→丁`으로 교체한다.

같은 절의 癸水가 丁·丙을 제약하는 문맥은 adjusted water 35% 이상일 때 blocker context로 기록한다. blocker는 선호 천간이나 점수를 삭제하지 않는다. 이는 원문 필요도와 현재 명식의 방해 상태를 분리하기 위함이다.

원문에 월 전반/후반, 복수 조건, `參酌`, 상반된 과다 조건이 함께 나타나 기본 순위만으로 모두 표현할 수 없는 11개 칸에는 `curationNote`를 붙였다: 甲午, 甲未, 丙亥, 庚寅, 庚卯, 庚辰, 庚巳, 辛子, 辛丑, 壬巳, 癸亥. 세부 조건을 임의로 확정하지 않고 후속 source revision 대상으로 남긴다.

## Urgency and normalization

urgency는 각 cell에 명시적으로 저장하며 runtime 계절 공식으로 생성하지 않는다. 혹한·혹서 문맥이 직접 강한 칸은 CRITICAL, 뚜렷한 한난조습 조절은 HIGH, 통상 선후 선택은 MEDIUM으로 편집했다. LOW는 v1에 없지만 schema가 허용한다.

천간 availability는 선호도와 독립이다. 년간·월간·시간의 동일 천간은 VISIBLE, 지장간 본기·중기·여기는 HIDDEN, 둘 다 없으면 ABSENT다. 일간 자체 동일 여부는 `dayStemSelf`로 따로 기록한다. 실제 transformation 관계 참여도 context로 남기지만 선호 점수를 바꾸지 않는다.

오행 집계는 같은 오행의 천간 점수를 내림차순으로 정렬한 뒤 `1.0, 0.5, 0.25, 0.125`를 곱해 합한다. 예를 들어 甲+酉의 丁 30, 丙 20은 火 `30 + 20×0.5 = 40`, 庚 10은 金 10이다. 이 수치는 고전 점수가 아니라 향후 synthesis를 위한 POSTPOST 정규화 계수다.
