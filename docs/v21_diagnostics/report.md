# 사주빛 V21 — RC11 후보 탈락 근거 추적

V20 기반 로컬 개발본. 로직 변경 없이 12개 명식 재실행 및 RC11 09 후보별 평가 추적.

- 전체: 120; 선정: 119; 구조화/원고 검토 가능: 96/96; 미선정: 1
- RC11 09 구조화 후보 생성: 9; 선정된 구조화 후보: False; 10번 선정: False
- 추적된 구조화 후보 전부 SEMANTIC_OVERLAP 사유로 반려됨. 직전 보고의 7개와 달리 현재 생성 단계에서는 9개이며 수치는 서로 다른 필터 단계에 관한 것으로 보임.
- 문구 교체 실험은 선정 수가 118로 악화돼 폐기. 원본 행동 생성·편집 로직 유지.
- 배포 차단 유지. 독립적인 신규 해석 장면은 근거 확립 전 추가하지 않음.

## 남은 일

RC11의 실제 원국 근거를 기준으로 09번의 9개 후보와 앞 8개 절 장면의 행동/판단/상황을 개별 대조한 뒤, 그 근거로만 생성 규칙을 수정해야 함. 회귀 실패 V6/V8/V13/V15도 여전히 미해결. 실서비스 API 검증 없음.
